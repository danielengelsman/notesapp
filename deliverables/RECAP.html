Run it yourself

Demo the product in three minutes

Requires Node 20+ (built on Node 22). From the repository root:

# from the repo root
npm install
npm run fixtures     # build the deterministic sample company
npm test             # 35 engine tests, incl. penny-perfect reconciliation
npm run build        # static export to out/
npx serve out        # → http://localhost:3000
  1. Open the site → “Open Bookstead” (or go straight to /app/).
  2. Click “Try the sample company” → “Run the free check.” Watch 1,369 transactions across six years reconcile against QuickBooks' own trial balance — every account, Δ 0.00.
  3. Download the archive — one self-contained .html. Open it: search transactions, drill accounts, print a P&L. It works offline, forever, with no Bookstead account.
  4. Download the migration pack — a .zip with GnuCash, Manager.io, and generic CSV/JSON exports, each with import instructions.
  5. Test the paid flow — on your own files, downloads are license-gated. Use the key in deliverables/DEMO_LICENSE.txt, or mint one: npx tsx scripts/make-license.ts you@example.com. It's verified in-browser with Ed25519 — no server is contacted.
The privacy claim is enforced by architecture, not policy: the whole app is a static export with a connect-src 'self' CSP. Load the app, turn off your wifi, and every step above still works.

How it was built

The arc — nine phases, orchestrated by agents

  1. Hunt for pain. 12 researchers swept small-business, trades, HN, SaaS-review, freelancer, clinic, landlord and other communities → 53 documented pains, each with quotes and URLs.
  2. Verify & shortlist. Skeptic agents tried to refute each; 5 of the top 8 were killed as already-served. The recurring anger: subscription creep and data hostage-taking.
  3. Tournament. 5 founder agents pitched competing businesses; a 4-lens judge panel (investor / customer / builder / distribution) scored them. Winner: the QuickBooks-Desktop escape.
  4. Design the business. 7 specialist agents (market, competition, pricing, GTM, legal, tech-spec, naming) produced sourced dossiers → the business plan.
  5. Brand. Named Bookstead (the working name “Ledgerlift” was killed by a real trademark collision), logo, palette, voice.
  6. Build the product + site. A real conversion engine (parsers → ledger rebuild → reconciliation → archive & export generators), a marketing site, and the app — all client-side.
  7. Launch film. Motion graphics + real product footage, neural voiceover, assembled with ffmpeg.
  8. Founder film. The disclosure that the founder is an AI — turned into the trust argument.
  9. Try to kill it. 4 adversarial agents (fact-check, product QA, business red-team, completeness critic). They found a stale price, a P0 CSV-injection bug, a license bypass, and more — all fixed and regression-tested.

Every decision, with rationale, is in DECISIONS.md (D-001 … D-016).
